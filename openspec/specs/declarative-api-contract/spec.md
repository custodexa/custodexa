# declarative-api-contract Specification

## Purpose
定義管理 API 供宣告式工具使用所需的契約：主線資源可依識別讀取單筆、以名稱精確查找、刪除後可用同名重建、寫入回應與隨後讀取一致、分頁參數如實回報，以及資產的更新與建立採用相同的欄位規則。
## Requirements
### Requirement: 主線資源可依識別讀取單筆

系統 SHALL 為節點、使用者群組、授權規則、資產帳號各提供一支依識別讀取單筆的端點。單筆讀取的回應 SHALL 與同一位呼叫者在同一時刻於對應列表中看到的那一筆相同（欄位與投影相同）；唯一例外是節點的單筆讀取 SHALL NOT 帶列表內嵌的直掛資產清單。呼叫者在對應列表中看不到的資源，單筆讀取 SHALL 回 404，其狀態碼、機器碼與本文 SHALL 與資源不存在時相同。單筆讀取所需的權限、是否對 API token 開放、是否對自動化主體開放，SHALL 與對應的列表端點相同；缺少該權限的呼叫者 SHALL 得到與呼叫列表端點時相同的拒絕。資產帳號的單筆讀取 SHALL 只涵蓋登入用途的帳號，系統專用帳號的識別 SHALL 與不存在的帳號得到相同回應。節點單筆讀取的比對基準 SHALL 為未帶用途參數的節點列表。以 API token 認證時，比對基準 SHALL 為同一把 token 所見的列表，SHALL NOT 為所屬帳號以登入工作階段所見的列表。

#### Scenario: 讀取單筆節點
- **WHEN** 具節點檢視能力者依識別讀取一個存在且可見的節點
- **THEN** 回 200，內容含識別、名稱、描述、上層節點與完整路徑，不含直掛資產清單

#### Scenario: 讀取單筆使用者群組
- **WHEN** 具使用者群組管理能力者依識別讀取一個群組
- **THEN** 回 200，內容與該群組在列表中的那一筆相同，含成員與成員來源

#### Scenario: 讀取單筆授權規則
- **WHEN** 具授權規則管理能力者依識別讀取一筆客體在其管理範圍內的規則
- **THEN** 回 200，內容與該規則在列表中的那一列相同

#### Scenario: 管理範圍外的授權規則
- **WHEN** 只經節點範圍指派持有授權規則管理能力者，依識別讀取一筆客體在其範圍外的規則
- **THEN** 回 404，與讀取不存在的規則時的回應相同

#### Scenario: 讀取單筆資產帳號
- **WHEN** 可見該資產者依識別讀取其下一筆在自己帳號範圍內的帳號
- **THEN** 回 200，內容與該帳號在帳號列表中的那一列相同，憑證識別欄位依呼叫者的能力決定是否出現

#### Scenario: 帳號範圍外的資產帳號
- **WHEN** 呼叫者依識別讀取一筆不在自己帳號範圍內的資產帳號
- **THEN** 回 404，與讀取不存在的帳號時的回應相同

#### Scenario: 秘密不出站
- **WHEN** 任何主體讀取單筆資產帳號
- **THEN** 回應不含密碼、私鑰或其密文，只以布林欄位表示是否已設定

#### Scenario: 已刪除的資源
- **WHEN** 依識別讀取一筆已刪除的節點、群組、授權規則或資產帳號
- **THEN** 回 404

#### Scenario: 以 API token 讀取
- **WHEN** 以授權了對應管理角色的 API token 讀取單筆
- **THEN** 結果與同一把 token 在對應列表中看到的那一筆相同

#### Scenario: 本人權限大於 token
- **WHEN** 所屬帳號是超級管理者，token 只被授權一個節點範圍的管理角色，以該 token 依識別讀取一筆範圍外的授權規則
- **THEN** 回 404，與讀取不存在的規則時相同；所屬帳號以登入工作階段讀取同一筆則成功

#### Scenario: token 沒有憑證檢視能力
- **WHEN** 所屬帳號具憑證檢視能力，token 被授權的角色不含該能力，以該 token 讀取單筆資產帳號
- **THEN** 回應為不含憑證識別欄位的精簡形狀

#### Scenario: 系統專用帳號的識別
- **WHEN** 以一台資產的系統專用帳號的識別呼叫資產帳號單筆讀取
- **THEN** 回 404，與讀取不存在的帳號時相同

#### Scenario: 缺少管理能力
- **WHEN** 沒有使用者群組管理能力的呼叫者依識別讀取使用者群組
- **THEN** 回應與該呼叫者呼叫群組列表時的拒絕相同，不因識別是否存在而不同

### Requirement: 以名稱精確查找

資產、節點、使用者群組、共用憑證的列表 SHALL 接受 `name` 參數，使用者列表 SHALL 接受 `username` 參數，只回名稱與參數值完全相符的資源。比對規則 SHALL 與該資源在建立時判定名稱重複所用的規則相同，系統 SHALL NOT 為查找另行改寫大小寫或空白。此參數 SHALL 與既有篩選以交集並用，並 SHALL 在可見範圍的收斂之後、計數與分頁之前套用。參數值為空字串時系統 SHALL 回 400。未帶此參數時列表行為 SHALL 不變。

#### Scenario: 找到既有資產
- **WHEN** 以 `name` 查找一台存在的資產，值與其名稱完全相符
- **THEN** 回應只含該資產，總數為 1

#### Scenario: 名稱只是部分相符
- **WHEN** 以 `name` 查找，值是某資產名稱的前半段
- **THEN** 回應不含該資產

#### Scenario: 找不到
- **WHEN** 以 `username` 查找一個不存在的使用者名稱
- **THEN** 回 200，資料為空、總數為 0

#### Scenario: 與建立時的重複判定一致
- **WHEN** 以某個名稱建立資源被判為名稱重複，且造成重複的那一筆對呼叫者可見、符合請求的其他篩選
- **THEN** 以同一個名稱查找，回應含那一筆既有資源

#### Scenario: 撞名不賦予查閱資格
- **WHEN** 建立使用者時因使用者名稱與一個自動化帳號相同而被判重複，再以該使用者名稱查找且未要求包含自動化帳號
- **THEN** 回應不含該自動化帳號

#### Scenario: 建立時不視為重複的變體
- **WHEN** 兩個名稱只差大小寫，而該資源建立時不把它們視為重複
- **THEN** 以其中一個查找，只回名稱完全相同的那一筆

#### Scenario: 節點同名
- **WHEN** 兩個不同上層節點之下各有一個同名節點，以該名稱查找
- **THEN** 回應含這兩個節點，各帶自己的上層節點

#### Scenario: 可見範圍外
- **WHEN** 呼叫者以名稱查找一筆存在、但不在其可見範圍內的資源
- **THEN** 回應與該名稱不存在時相同

#### Scenario: 空值
- **WHEN** 帶了 `name` 參數但值為空字串
- **THEN** 回 400

### Requirement: 刪除後可用同名重建

節點、資產、使用者、使用者群組、授權規則刪除之後，系統 SHALL 允許以相同的名稱（授權規則為相同的主體、客體與等級）重新建立。名稱的唯一性 SHALL 只計未刪除的資源。已刪除資源在稽核紀錄與歷史清單中呈現的名稱 SHALL 不因此改變。

#### Scenario: 使用者群組同名重建
- **WHEN** 刪除一個使用者群組後，以同一個名稱建立群組
- **THEN** 建立成功，得到新的識別；原群組連動撤銷的授權不恢復

#### Scenario: 未刪除的群組仍不可重名
- **WHEN** 以一個現存群組的名稱建立群組
- **THEN** 回 409

#### Scenario: 已刪除群組的歷史呈現
- **WHEN** 刪除群組後檢視當時的稽核紀錄
- **THEN** 紀錄中的群組名稱為刪除當時的名稱

### Requirement: 寫入回應與讀取一致

節點、資產、資產帳號、使用者、使用者群組（含成員與角色指派）、授權規則、共用憑證的建立與更新端點，其成功回應中凡與該資源讀取端點同名的欄位，值 SHALL 等於寫入完成後立即讀取所得。節點寫入回應 SHALL 帶完整路徑，使用者群組的寫入回應 SHALL 帶成員識別清單與成員來源；刻意只出現在寫入回應或讀取回應其中一方的欄位不在此限。資產單筆讀取的待配憑證欄位 SHALL 與資產列表採用相同的判定：沒有未刪除的登入用途帳號時為是。

#### Scenario: 清空資產的節點歸屬
- **WHEN** 更新一台資產，把節點歸屬設為空
- **THEN** 回應的節點歸屬為空，與隨後讀取該資產所得相同

#### Scenario: 替換群組成員
- **WHEN** 以整組替換設定一個群組的成員
- **THEN** 回應的成員識別清單與成員來源等於隨後讀取該群組所得

#### Scenario: 節點寫入回應帶路徑
- **WHEN** 建立、更名或搬移一個節點
- **THEN** 回應帶寫入後的完整路徑，與隨後讀取該節點所得相同

#### Scenario: 待配憑證
- **WHEN** 讀取一台沒有任何登入用途帳號的資產
- **THEN** 待配憑證欄位為是；為它建立一筆帳號後再讀取，該欄位為否

#### Scenario: 只有系統專用帳號
- **WHEN** 讀取一台只設定了系統專用帳號、沒有登入用途帳號的資產
- **THEN** 待配憑證欄位為是，與資產列表中該筆相同

### Requirement: 分頁參數如實

資產、使用者、授權規則、共用憑證的列表在分頁時 SHALL 於回應中帶實際套用的頁碼與每頁筆數。請求的每頁筆數超過該端點的上限時，系統 SHALL 套用上限，SHALL NOT 改用預設值或其他較小的值。各端點對不合法分頁值（小於 1 或不是數字）的既有處理 SHALL 不變：授權規則與使用者列表套用預設值，共用憑證列表回 400。

#### Scenario: 授權列表超過上限
- **WHEN** 以每頁 500 筆請求授權列表，上限為 100
- **THEN** 回應的每頁筆數為 100，資料至多 100 筆

#### Scenario: 使用者列表回報分頁
- **WHEN** 以每頁 2 筆請求使用者列表
- **THEN** 回應帶頁碼與每頁筆數 2，資料至多 2 筆，總數為全部符合條件的筆數

#### Scenario: 選用分頁的列表
- **WHEN** 請求共用憑證列表並帶頁碼
- **THEN** 回應帶實際套用的頁碼與每頁筆數；未帶頁碼時回全部資料，行為不變

#### Scenario: 授權列表不合法的每頁筆數
- **WHEN** 請求授權列表的每頁筆數小於 1 或不是數字
- **THEN** 系統套用預設值，並在回應中帶該值

#### Scenario: 共用憑證列表不合法的分頁值
- **WHEN** 請求共用憑證列表的頁碼為 0 或每頁筆數不是數字
- **THEN** 回 400 並指出是哪一個參數，與現行行為相同

### Requirement: 資產的更新與建立採用相同的欄位規則

資產更新 SHALL 套用建立資產時的欄位規則，至少含埠號範圍與各協定對帳號名稱的要求。每條規則有其依賴的欄位：埠號規則依賴埠號；帳號名稱規則依賴協定、帳號名稱與登入秘密的有無。本次更新使某條規則的任一依賴欄位的值改變、且套用後的資產違反該規則時，系統 SHALL 回 400 並指出欄位，不寫入任何變更。請求帶了欄位但值與現值相同 SHALL NOT 視為改變；依賴欄位皆未改變的規則 SHALL NOT 因既有的值而使更新被拒。建立資產 SHALL 接受選用的啟用狀態欄位，省略時為啟用。

#### Scenario: 更新成不合法的埠號
- **WHEN** 更新一台資產，把埠號設為 0 或 70000
- **THEN** 回 400，資產的埠號不變

#### Scenario: 清空必填的帳號名稱
- **WHEN** 一台有登入密碼的 SSH 資產，更新時把帳號名稱設為空
- **THEN** 回 400，帳號名稱與密碼不變

#### Scenario: 無關欄位的更新不受既有值影響
- **WHEN** 一台資產的既有埠號不合現行規則，更新時改描述，並原樣帶上現有的協定與埠號
- **THEN** 更新成功

#### Scenario: 把不合規則的值改成另一個不合規則的值
- **WHEN** 一台資產的既有埠號不合現行規則，更新時把埠號改成另一個超出範圍的值
- **THEN** 回 400，埠號不變

#### Scenario: 改協定使帳號名稱變成必填
- **WHEN** 一台只有密碼、沒有帳號名稱的資產，更新時把協定改成需要帳號名稱的協定，未帶帳號名稱
- **THEN** 回 400，協定不變

#### Scenario: 新增秘密但沒有帳號名稱
- **WHEN** 一台沒有憑證也沒有帳號名稱的 SSH 資產，更新時只帶入密碼
- **THEN** 回 400，不建立任何憑證

#### Scenario: 建立時指定為停用
- **WHEN** 建立資產並指定為停用
- **THEN** 建立成功，資產自建立起即為停用，中間沒有啟用的狀態

#### Scenario: 建立時未指定
- **WHEN** 建立資產而未帶啟用狀態
- **THEN** 資產為啟用
