以下の四つの値をこのホストに合わせます。
それ以外の設定はすべてバックアップを引き継ぎます。

[ ?? ] データフォルダー DATA_PATH
       バックアップの値  /data/custodexa
       このホストの推奨値  /opt/custodexa/data
Enter で推奨値、- でバックアップの値を使います。
または別の絶対パスを入力してください > 

[ ?? ] 証明書のホスト名 TLS_DOMAIN
       バックアップの値  bastion-a.example.internal
       このホストの推奨値  bastion-b.example.internal
Enter で推奨値、- でバックアップの値を使います。
または別の値を入力してください > 

[ ?? ] 証明書の IP TLS_IP_SAN
       バックアップの値  10.0.0.12
       このホストの推奨値  10.0.0.31
Enter で推奨値、- でバックアップの値を使います。
または別の値を入力してください > 

[ ?? ] 公開 URL PUBLIC_BASE_URL
       バックアップの値  https://10.0.0.12
       このホストの推奨値  https://10.0.0.31
Enter で推奨値、- でバックアップの値を使います。
または別の値を入力してください >
